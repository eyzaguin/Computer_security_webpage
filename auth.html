Authentication Demo

Practice creating an account, logging in, and logging out.

Learning demo only — no backend.

This page keeps demo accounts in JavaScript memory in this tab only. Nothing is sent to a server or saved in browser storage. Reloading or closing the page clears every account and session. Never enter a real password here.

This demo confirms identity only. It does not provide access to protected server data or prove authorization.

1. Create an account

Choose a made-up email and demo password. Account details exist only until this page is reloaded or closed.

Use at least 8 characters, and do not use a real password.

2. Log in

Use the same demo email and password you just registered, while this page remains open.

What this demonstrates

  1. Create account: register a temporary demo identity.
  2. Log in: provide its credentials to simulate authentication.
  3. Log out: end the temporary signed-in state.

Real authentication requires a trusted backend to securely store password hashes, verify credentials, manage sessions, and enforce authorization. A client-only page cannot securely authenticate users or protect private resources.
